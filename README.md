# Mystic Valley 🔮

![Mystic Valley Banner](https://via.placeholder.com/1280x640/1a0033/AE81FF?text=Mystic+Valley)

> *«Долина должна дышать: шёпоты говорят, истории живут, персонажи помнят…»*

**Mystic Valley** — это кроссплатформенное мобильное приложение на .NET MAUI, которое погружает вас в мир мистических предсказаний и "живого" процедурного нарратива. Это не просто "гадание дня", это интерактивная история, где вы — главный зритель и катализатор событий.

Каждое ваше взаимодействие с одним из девяти уникальных персонажей запускает два параллельных потока: вы получаете личное, загадочное предсказание и одновременно становитесь свидетелем нового эпизода в глобальной драме Долины.

---

## ✨ Ключевые Особенности

*   **Двойной Опыт:** Получайте личные предсказания от оракулов Долины и наблюдайте за развитием глобального сюжета, который разворачивается как "интерактивный сериал".
*   **"Живой Сценарий":** Реплики персонажей в "сериале" не являются статичным текстом. Они генерируются AI на основе сценарной канвы, что делает каждое прохождение уникальным и непредсказуемым.
*   **Память Мира:** Приложение помнит ваш прогресс по сюжету и эмоциональное состояние персонажей, готовя почву для будущих событий.
*   **Кинематографическая Подача:** Динамически создаваемые и анимированные блоки диалогов с цветовой кодировкой эмоций создают ощущение живого театрального представления.
*   **Кроссплатформенность:** Создано на .NET MAUI для работы на Android и Windows.

---

## 🛠️ Технологический стек

*   **Фреймворк:** .NET MAUI (.NET 8)
*   **Язык:** C#
*   **Архитектура:** MVVM, Dependency Injection, Service-ориентированный подход.
*   **Искусственный Интеллект:** GigaChat API для генерации предсказаний и импровизированных диалогов.
*   **Безопасность:** Управление API-ключами через `.NET User Secrets`.
*   **Хранение данных:** Локальные JSON-файлы (`history.json`, `whispers.json`, `gamestate.json`).
